# Kibera Rising

An original open-world crime game on an island that never existed. Drive the Sable GT through golden-hour pursuits on Kumala Strand, clear the aisles of the Pasaru night market with your crew, and climb from street rat to Kingpin of Kibera across six story missions. Built with Three.js, fully offline, keyboard & mouse.

## Play

```sh
node serve.ts
```

Then open the printed URL (http://localhost:8080 by default).
